# Digital Printing

With **Digital Printing** you will be able to customize Sneakers with any image you choose, and **we will print your design on the leather**.&#x20;

We built a completely new designing panel. First, select a style from the Digital Printing section and use the parts widget to **customize each shoe piece individually**. Selecting a piece will open the side panel, where you can start designing.

We made some video tutorials to explain all features and customization capabilities. Check them out!
